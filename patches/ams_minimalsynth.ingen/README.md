# ams-minimalsynth

Minimal viable alsamodularsynth-lv2 patch. Can be either loaded in
[ingen](https://github.com/drobilla/ingen), or
[PicoLV2](https://github.com/Joeboy/PicoLV2) (on a Raspberry Pi Pico 2).

Needs [this](https://github.com/Joeboy/ams-lv2/tree/picolv2-build) repo / branch
of ams-lv2 to work on the Pico.
